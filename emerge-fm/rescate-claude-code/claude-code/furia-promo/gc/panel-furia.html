Conexión con OBS Sin conectar

Sin conexión, el panel igual sirve para preparar textos: copia esta dirección en la fuente de navegador de OBS.

Cómo se usa

  1. En OBS agrega una Fuente de navegador de 1920 × 1080 con el archivo local gc-furia.html de esta carpeta. Desmarca «Apagar la fuente cuando no sea visible».
  2. Opcional: agrega otra fuente de navegador con gc-furia.html?modo=mosca para la mosca del programa (logo, EN VIVO y hora).
  3. Abre este panel como acoplable: Acoplables → Acoplables de navegador personalizados, con la ruta de panel-furia.html.
  4. En OBS: Herramientas → Configuración del servidor WebSocket → Habilitar. Copia la contraseña aquí y pulsa Conectar: el panel encuentra sola la fuente que tiene gc-furia.html (si hay varias, elige cuál).
  5. Escribe, revisa la vista previa y pulsa Mostrar al aire. Ocultar la saca con su animación. Actualizar texto corrige un texto que ya está al aire sin repetir la entrada.
